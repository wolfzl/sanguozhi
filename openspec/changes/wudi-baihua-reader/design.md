## Context

原文保存在book.json，阅读页通过OpenCC切换文字节点。译稿沿用128个原文块和122个注文ID。

## Decisions

- 独立保存卷001译稿，在构建时渲染到template。激活白话时替换阅读区子节点，避免同时存在重复ID；返回原文时复用原节点及字形缓存。
- 阅读区元素保持不变，原有裴注显隐控制继续有效。按段落ID恢复切换前的可见位置。
- 保留旧字形偏好，另存阅读模式；经过无译文的卷目时回退上次字形，不清除白话偏好。
- 译文按段落安全渲染文本，仅识别HTTP(S) Markdown链接；显示AI辅助试译说明。

## Risks / Trade-offs

- 译文增加卷001静态HTML体积；其他卷不包含译文。
- 译稿仍属试译，界面注明并支持切回原文。

## Migration Plan

新worktree实现并验证，快进合并到现有网站分支，构建并重启原有本地预览。需要回退时可撤销功能提交后重新构建。
