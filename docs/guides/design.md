# 三国志 · 人物与事件

目标：提供大众可读、手机友好、可追查原文的历史卡片网站。首版包含 12 位人物、8 个事件、65 卷原文及《上三国志注表》。

采用 Astro + TypeScript 静态生成，浏览器完成简繁搜索、势力筛选和分享。无账号、数据库、外部 AI 接口或自动发布。

阅读路径：首页 → 人物 → 事件 → 其他人物 → 原文。人物、事件、原文分别使用独立 URL。卡片为简体解读，原文保留繁体和裴注层级；引文区分陈寿正文与裴注所引文献。

原文从用户指定 EPUB 提取，按 OPF 阅读顺序处理。块 ID 与 EPUB SHA-256 共同固定来源版本。内嵌注文使用行内 span 保持合法 HTML，视觉上独立成块；独立注文使用 aside。

人物：曹操、袁绍、刘备、孙权、诸葛亮、关羽、张飞、赵云、周瑜、鲁肃、吕蒙、陆逊。

事件：曹操迎汉献帝、官渡之战、赤壁之战、刘备入蜀、汉中之战、关羽失荆州、夷陵之战、诸葛亮首次北伐。

暖白、深墨、朱红的排版风格；使用文字和抽象图形，不制作虚构人物画像。版本来源与 CC BY-SA 4.0 信息全站可见。
