# 人物小传统一改写（3.2）

本轮按用户认可的司马昭样本，改写其余64位人物。人物总数65，覆盖汉末16、曹魏16、蜀汉15、孙吴15、西晋3；司马昭正文保持，相关事件列表补入新页。

## 内容原则

- 每人以300—500字的小传串联身份、家世、关键行动与终局，保留有代表性的正文与裴注故事。
- 全65人提供生卒依据。确载、享年逆推、不同纪年及不详分别标明；麋竺、孙乾、程普等保留可证的相对卒年，不用流行年表填空。
- 正文事件写年份并给站内入口，关键经历每条标明纪年或不详范围；合并经历涉及多事件时全部链接可见。
- 补充重要家族、师友与政治关系。定向关系从目标人物身份表述；不自动反转所有政治标签。
- 主要依据本地《三国志》与裴注；晋代少数人物的生卒、字号取实际核实的《晋书》卷001、002、003、034、042，另列来源。
- 引用复合裴注时以实际引句所属书籍为准，不把整条注文的第一部书名套给全部引文。
