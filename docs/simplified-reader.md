# 原文阅读简繁切换

实施日期：2026-10-09。基于事件线第二版 `9d2951e`，开发分支 `feat/sanguozhi-simplified`，worktree 为 `/Users/zhangliang/ai/readbook/tmp/sanguozhi-simplified`。

## 设计与范围

在现有 `/read/{volume}/` 阅读页工具栏增加“简体／繁体”两个按钮。首次阅读默认简体，浏览器通过 `sanguo-reader-script` localStorage 键记住选择，刷新、换卷继续使用。存储被禁用或读取异常时默认简体，页面仍可正常切换。

使用已有 `opencc-js` 1.4.2 的 `t → cn` 转换，仅处理阅读区的文字节点，包含陈寿正文、裴松之注、阅读区内标题和引书名称。原始数据不增加字段，也不生成另一套阅读页面。每个文字节点保存底本原字形与简体结果；切回繁体直接恢复底本，不通过简转繁反推，以保留合并字及异体字。

页面路径、标签层级、原文块 ID、注文 ID、类名和链接属性保持原样。字形切换保持当前可见段落位置；原有的隐藏裴注、引用目标自动展开、高亮及卷目导航继续使用。阅读区语言标签随切换更新为 `zh-Hans` 或 `zh-Hant`，按钮提供 `aria-pressed` 状态。

手机工具栏的卷目选择单独占一行，字形与裴注按钮位于下一行；桌面维持同一行。JavaScript 不可用时显示完整繁体底本，隐藏字形按钮，并提示可启用 JavaScript 获得简体显示。转换库随静态构建交付，无外部转换服务、网络 API 或运行时 AI。

人物与事件卡片的原文节选继续保留底本字形。简体原文属于同一底本的自动字形转换，未另换版本，也不等于人工校勘；古籍特殊字形可切回繁体对照。关于本书页面已记录这一处理方式，来源修订链接和许可声明继续保留。

## 验证结果

环境：Node.js 25.6.0、Astro 5.18.2、Playwright Chromium。

- 修改前 `npm test`：6 项 Python 测试、15 项 Node 测试通过。
- 新增阅读检查先在旧版执行，因正文未显示简体而失败，确认检查能识别功能缺失。
- 修改后 `npm test`：21 项测试通过，未跳过原书比对测试。
- `npm run build`：内容及引用校验通过，Astro 检查 0 errors、0 warnings；144 个静态页面生成成功。保留的 1 个 hint 为既有复制兼容逻辑所用 `document.execCommand` 的弃用提示。
- `npm run test:reader`：66 个阅读单元逐卷确认简体显示、常见繁体字转换、内部 DOM 属性完整保留；切回繁体后的阅读区 HTML 与关闭 JavaScript 时的底本完全一致，覆盖正文和全部 1,822 个裴注元素。
- 阅读交互验证：选择跨刷新与翻页保留；反复简繁切换不改变引用 URL 或目标高亮；从隐藏裴注状态进入注文锚点可自动显示；禁用存储后仍可转换及恢复；关闭 JavaScript 时保留繁体可读内容。
- 阅读布局验证：320、390、768、1440 像素宽度无横向溢出，新增按钮不与裴注按钮重叠。已查看手机及桌面截图。
- `npm run test:browser`：143 个正常页面、4,918 个站内链接和锚点通过；原有搜索、时间线筛选与历史恢复、事件关系、分享回退、裴注目标和手机布局通过。

滚动检查使用可见按钮坐标上的真实鼠标事件。排查发现 Playwright `Locator.click()` 会在 sticky 工具栏点击前主动调整滚动位置，不能据此判断用户点击导致的位置变化；鼠标事件检查确认简繁切换保持引用目标可见。

这些检查验证软件转换、结构保留与页面交互，不代表对古籍全文进行人工逐字校勘。
