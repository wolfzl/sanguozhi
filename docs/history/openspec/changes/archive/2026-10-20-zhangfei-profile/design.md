## Context
65 existing Astro portraits are generated by Python. Only Zhang Fei has approved dossier content.

## Goals / Non-Goals
Publish the approved content at the existing route and keep all source and event links. Do not recategorize or rewrite the other 64 portraits.

## Decisions
Use an optional dossier object for metadata, achievements, setbacks, glossary and plain-name related figures. Reuse milestones as the sole career timeline, adding office changes to each entry. Existing portraits retain their current layout. Extend the generator rather than directly maintaining generated JSON. Render real HTML tables with stacked mobile rows. Show an explicit civil-achievement empty state instead of inventing governance results. Keep source excerpts in the existing expandable reference list.

## Risks / Trade-offs
Longer biography and timeline exceed the legacy limits: permit up to 800 characters and 12 milestones only for dossiers. Uncreated related person pages: render their names without fabricated links. Unknown dates remain visibly uncertain.

## Migration Plan
Verify generation, tests, build and desktop/mobile browser behavior, then fast-forward the clean local website checkout and rebuild/restart its preview. Rollback uses Git revert of the feature commit and rebuild.
