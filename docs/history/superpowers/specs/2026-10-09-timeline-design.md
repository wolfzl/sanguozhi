# 三国志事件线升级设计（用户已确认）
目标：184—280 年完整事件线，38 个事件、34 位人物，暖白朱红风格；旧路由和原文保持稳定。
桌面共用年份轴、魏蜀吴三条线；共同背景置于三线之前；跨线事件只有一个 ID 与页面。曹氏→曹魏→西晋、刘备→蜀汉（263 终）、孙氏→孙吴（280 终）。同年对齐，年份非等距。
手机单列时间汇总，显示势力标签；默认关键，可选全部。组合筛选重要程度、势力、战争/政权/继承/外交/治理；搜索、筛选和视图进 URL，返回恢复。无脚本仍能读全部。
事件关系四类：context（背景与后果）、process（同一历史进程）、parallel（并行对照）、succession（政权承继）。每条解释及 refs，解读标记；关系与时间相邻导航分开。
内容全部基于 book.json；人物 300—500 字生平/3—5 节点，事件 400—700 字/背景经过结果影响；每部分有准确引句。司马氏注明本书散见材料边界。无卡人物纯文本。
保持原文 65 卷和附表、许可和修订链接。验证内容/互链/关系/旧网址/搜索/过滤/分享/320、390、1440 布局与全站内部锚点。

实施裁定：所有234年事件归第二阶段（16节点），第三阶段从239开始（13节点），第一阶段9节点，总计38；同年共用唯一年份组。

分类定义：state为建国、帝号建立和王朝更替/结束；succession包含朝内废立与权力移转。地方势力经营不自动等同建国。
